# Protocol_Focus_Engine_Project
Protocol Focus Engine is an advanced cyberpunk-themed web application that simulates human productivity using Object-Oriented Programming principles. The system tracks mental focus and physical energy through interactive tasks categorized as Deep Work, Physical Training, and Maintenance activities. Featuring animated holographic visuals, particle systems, glitch effects, and live system logs, the application creates an immersive futuristic operating-system experience while demonstrating core OOP pillars such as Encapsulation, Inheritance, Abstraction, and Polymorphism using JavaScript classes.
